GitHub Copilot AI Credits Lab

Learn the current usage-based model, understand the legacy exception, then forecast plan usage.

GitHub billing model
Billing Transition · June 1, 2026

From premium-request multipliers
to token-based AI Credits

GitHub documents usage-based AI Credits as the current billing model. Premium-request multipliers continue only for eligible existing annual Copilot Pro and Pro+ subscribers who remain on the legacy model after June 1, 2026.

Legacy: Premium Requests

For qualifying existing annual Pro / Pro+ subscribers only.

  • One interaction consumes a request multiplied by model weight.
  • Powerful model multipliers can be high.
  • Not the current AI Credit formula.

Current: AI Credits

Usage-based calculation from token consumption.

  • Input, output and cached tokens are model-priced.
  • Total cost converts to AI Credits.
  • 1 AI Credit = $0.01 USD.
Do not compare PRUs as dollars. The old unit is a request multiplier; the new unit is token-priced AI Credit usage. The legacy view is included only to explain the billing change.
GitHub Copilot AI Credit formula
AI Credits = {[(input × input rate) + (cached × cached rate) + (cache write × write rate where published) + (output × output rate)] ÷ 1,000,000} ÷ $0.01
