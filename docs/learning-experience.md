# Learning Experience Design

TokenOps teaches two distinct cost models before it asks users to calculate anything.

## API Model Cost Lab curriculum

1. Input, output, cached-input and cache-write token economics.
2. Processing modes such as standard, batch, flex and priority where provider documentation publishes them.
3. Context threshold changes and provider-specific caveats.
4. Six practical cost-control levers.
5. Scenario calculator and comparable model-cost output.

## GitHub Copilot AI Credits Lab curriculum

1. Legacy premium requests versus current token-priced AI Credits.
2. Critical applicability limitation: legacy multipliers apply only to eligible annual Pro and Pro+ subscribers remaining on legacy billing after June 1, 2026.
3. AI Credit formula and token anatomy.
4. Plan allowances, enterprise pooling and promotional amounts.
5. Same-task worked examples.
6. Legacy multiplier reference table for transition education only.
7. Eight budget-protection strategies, labeling documentation versus inference.
8. Usage calculator, code-review warning and model lifecycle watch.

## Content integrity rule

Teaching copy must not turn practical guidance into undocumented GitHub product claims. For example, minimizing unnecessary MCP/tool context is labeled as an optimization hypothesis to verify with actual usage data, not a guaranteed product billing rule.
