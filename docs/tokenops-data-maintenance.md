# TokenOps Data Maintenance

1. Review only official provider or GitHub product documentation.
2. Update the matching JSON registry, official source link and `verifiedOn` date.
3. Preserve retired or closing-down models with accurate lifecycle status.
4. Never silently mark a rate as verified without a primary official source.
5. Run `npm run validate` and `npm test` before pushing.
6. Record material changes in `portfolio/changelog.json` and `assets/data/tokenops-announcements.json`.
