# GitHub Copilot AI Credits Rules

GitHub documentation states that Copilot interactions consume input, output and cached tokens priced by model, and total cost is converted into GitHub AI Credits:

```text
1 AI Credit = $0.01 USD
AI Credits = Estimated USD Cost / 0.01
```

The estimator models included allowances for the selected plan and displays projected excess usage. Organization allowances are pooled by seat count.

## Auto model selection

The optional 10% discount is modeled only where GitHub documents eligibility: paid plans using auto model selection in Copilot Chat, Copilot CLI or Copilot cloud agent, and only for model names stored as eligible.

## Not modeled yet

- Actual GitHub Actions minutes used by Copilot code review.
- Feature-specific non-token infrastructure charges.
- Unpublished Free or Student credit allowance quantities.
